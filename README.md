# home:caiocco

Fontes de empacotamento (spec, patches, `.changes`, `_service`) do projeto
[home:caiocco](https://build.opensuse.org/project/show/home:caiocco) no
Open Build Service, voltado ao openSUSE Leap 16.0.

O OBS continua sendo onde os pacotes são construídos; este repositório é o
histórico e o backup do que é mantido aqui. Tarballs upstream e árvores
extraídas não são versionados (ver `.gitignore`): vêm do OBS ou do `_service`.

Pacotes que são link (`linkpac`) aparecem expandidos, como o `osc` os
baixa; a mudança local deles fica no `project.diff`, quando existe.

`verificar-atualizacoes.sh` compara os pacotes com a origem, a Factory e o
Repology.
